# RunTrack - Gestión de Sensores

Práctica AVS.03.03.01 de Desarrollo de Aplicaciones Móviles (UTEZ).

Aplicación Android en Kotlin que lee el **acelerómetro** y el **giroscopio** para detectar si el corredor está en movimiento y hacia dónde gira. Las lecturas se filtran con un umbral mínimo de cambio para evitar procesar datos repetidos.

## Requisitos
- Android Studio
- Dispositivo o emulador con Android 7.0 (API 24) o superior

## Ejecución
1. Clonar el repositorio y abrirlo en Android Studio.
2. Ejecutar en un dispositivo físico o en el emulador (Extended Controls > Virtual Sensors para simular movimiento).
